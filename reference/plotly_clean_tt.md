# Make replacements in plotly tooltips

Make replacements in plotly tooltips

## Usage

``` r
plotly_clean_tt(plotly, rep)
```

## Arguments

- plotly:

  A [`plotly`](https://rdrr.io/pkg/plotly/man/plotly.html) object.

- rep:

  A named character vector. Names are the text to replace and the string
  is the replacement string.

## Value

A [`plotly`](https://rdrr.io/pkg/plotly/man/plotly.html) object.
