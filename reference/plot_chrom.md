# Plot chromatogram

Plot chromatogram

## Usage

``` r
plot_chrom(tbl, RT_col = "RT", Intensity_col = "Intensity")
```

## Arguments

- tbl:

  tbl with retention time and intensity to plot

- RT_col:

  Name of the rentention time column

- Intensity_col:

  Name of the intensity column

## Value

a `ggplot` object.
